Experimentation Lab. Each lab lives in its own folder with its own README.

| Lab | What it is |
|---|---|
| `jobscan/` | Job board scanner: fetch, filter, score, rank. .NET 8, zero NuGet deps. Dashboard + Railway deploy. |
| `DeerStand/` | Privacy-first hunting club SaaS: stand map, check-ins, activity logs. ASP.NET 9 + Next.js. |
| `Cartographer/` | OSM-to-game-terrain cell grid: sentinel MapLibre render, classify, Postgres discovery API. |
| `iFlame/` | Pitch-black ambient focus workspace: quiet fire, rain, and noise. |
